# Jobs

A Job note is one note per task you do over and over. It gives the assistant the whole skill for that task: which notes to read first (the boot chain), the steps, what "done right" looks like, and lessons from your corrections. **Read one note, have the whole job.** The assistant loads that note and only the notes it points to, never the whole vault.

**Add a Job** any time you catch yourself explaining the same task twice: copy [[Job template]], fill it in (or ask the assistant to interview you for it), and add a line below.
