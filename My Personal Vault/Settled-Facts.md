# Settled Facts

**How to add one:** when I give an answer that should always be the same (a preference, a decision, a house rule), the AI adds a row here the same turn, with the date and my words. To change one, edit the row and its date; don't add a second row. Mark a row **Locked** if it must never change without me saying so. Never put a password, account number or card number here; say where it is stored.
