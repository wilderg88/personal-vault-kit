# Home

Everything about the place you live and how it runs: chores and cleaning routines, repairs and maintenance, appliance and warranty details, who to call (plumber, landlord), shopping and meal plans, and household projects. One note per topic. Repeating chores that you want the assistant to run the same way each time get a Job note in `09 - Routines and Jobs`, and this folder links to it.

Keep serial numbers and warranty dates here if useful, but never door codes, alarm codes, wifi passwords or account numbers; say where they are kept instead (for example "in my password manager").

**Keeping this list current:** whenever a note in this folder is created, renamed, moved or changed in a meaningful way, the assistant updates the list below (one line per note) in the same pass. When a note moves to another folder, it comes off this list and goes onto that folder's list.
